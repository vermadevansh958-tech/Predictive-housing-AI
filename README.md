# Predictive Housing AI Engine

## Project Objective
This repository contains a Machine Learning project designed to predict residential property prices based on key structural features: House Size (sq ft), Number of Bedrooms, and the Age of the Property.

## The AI Approach
I implemented a **Linear Regression** model using Python. The project demonstrates core data engineering fundamentals:
- Custom data engineering and synthesis of 200 data points.
- Dataset splitting (80% training, 20% testing).
- Performance validation achieving an R² score over 99.3%.

## Technical Stack
- **Language:** Python 3
- **Libraries:** NumPy, Pandas, Scikit-Learn
